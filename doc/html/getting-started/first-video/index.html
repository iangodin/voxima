    Your first video¶

    This builds the small example plugin that comes with Voxima, previews it in a window, and renders it to a video file. You need Voxima built and installed and the fonts.

    1. Copy the example¶

    cp -r <prefix>/share/voxima/examples/hello my-video
cd my-video

    It holds three files:

    • hello.cpp: one scene, written in C++.
    • scripts/en.huml: the words, for English (a title, here).
    • CMakeLists.txt: builds hello.cpp into a plugin.

    2. Look at the scene¶

    // A plugin of scenes: build it (see CMakeLists.txt), then
//
//     voxima --plugin build/hello --script-dir scripts --lang en --theme "Academic Classic" --preview
//
// With --preview, rebuilding it while the window is open plays the scene again with the change.

#include <core/Animate.h>
#include <core/Plugin.h>
#include <core/SceneRegistry.h>
#include <core/Script.h>
#include <core/Stage.h>
#include <core/Wait.h>
#include <visuals/Circle.h>
#include <visuals/CreateText.h>
#include <visuals/Placement.h>

#include <memory>
#include <string>

using namespace std::chrono_literals;

VOXIMA_PLUGIN();

namespace
{
Scene hello( Stage &stage, Script &script )
{
    Theme &theme = *stage.theme;
    const std::string title{ script.fetch( script.master_language(), "title" ).as_string() };

    auto &words = stage.visuals.add( make_text( theme, title, FontStyle{ Intent::TITLE }.large() ) );
    move_to( words, { 0.F, 1.5F } );

    auto circle = std::make_unique<Circle>();
    circle->radius = 1.F;
    circle->color = theme.palette().blue;
    auto &dot = stage.visuals.add( std::move( circle ) );
    dot.position = { 0.F, -1.5F };

    co_await fade_in( stage, words, 0.8s );
    co_await grow_in( stage, dot, 0.6s );
    co_await indicate( stage, dot );
    co_await wait_for( stage, 1s );
}
}

// With one scene registered, it is what plays without --scene (several plugins together: name it with --scene)
REGISTER_SCENE( "hello", "A title and a circle", hello );

    Read it top to bottom:

    • VOXIMA_PLUGIN(); marks the file as a plugin. It says which compiler and library it was built with, so voxima can refuse a mismatch.
    • hello is a scene: a coroutine that receives the Stage (what is drawn) and the Script (the words).
    • The text and the circle are visuals, added to stage.visuals. Then fade_in and grow_in bring them in from nothing.
    • co_await plays an animation and continues when it is over. Each line takes the time it names.
    • REGISTER_SCENE( "hello", ... ) gives the scene a name. With only one scene registered, that is what plays when you do not ask for another.

    3. Build the plugin¶

    Plugins are built with CMake, against the installed Voxima (<voxima> is your checkout):

    cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=<prefix> \
    -DCMAKE_TOOLCHAIN_FILE=<voxima>/build/Release/generators/conan_toolchain.cmake
cmake --build build

    The build type, the compiler and the standard library must be those Voxima was built with, which they are if you use the same compiler. The Conan toolchain file gives CMake the libraries the headers include (lunasvg, FreeType, libsndfile); see Your own plugin project.

    You now have build/hello.so (build\hello.dll on Windows).

    4. Preview it¶

    <prefix>/bin/voxima --plugin build/hello --script-dir scripts --lang en \
    --theme "Academic Classic" --preview

    A window opens and plays the scene. Leave it open, edit hello.cpp (change a color, a time, the circle's size), and rebuild: the scene starts again with your change, on its own. (F5 reloads the script too, so you can change the words just as quickly.) Space pauses; Esc closes the window.

    5. Render it¶

    <prefix>/bin/voxima --plugin build/hello --script-dir scripts --lang en \
    --theme "Academic Classic" --render-dir render

    The video is render/final.mkv. Choose the format with --container (mp4, mkv, webm), --vcodec and --acodec, and the size with --width, --height and --fps. Rendering lists what is left in the render directory.
